## 3. What remains

- **DEBT-005** — no LiveKit test project, so PROF-08 is unsupported and every voice row is blocked.
- **DEBT-006** — PROF-03 packet-loss remains unsupported; degraded-network behaviour is unmeasured.
- **DEBT-003** — 22 of 28 C4 metrics still have no Measured Baseline, and no Certified Threshold is
  set for any metric. Thresholds are set by a human after measurement, never by a generator.
- Chat and Moderation engines have no modules mapped (DEBT-020).
- Accessibility certification remains an automated subset; a manual WCAG 2.1 AA audit is outstanding.

None of these blocks feature development. All are tracked with an owner, milestone and engine.

## 4. Constitutional limit (binding)

M0.5 is the **final infrastructure sprint**. From here:

- No further infrastructure, governance documents, certification frameworks, dashboards, engineering
  reports, ADR restructuring, architecture chapters, or developer tooling may be introduced — unless a
  blocker is discovered during implementation or certification, in which case the change is scoped to
  removing that blocker and nothing else.
- StreamFlow enters **M1 Build Mode immediately** on successful M0.5 completion.
- Future work prioritises user-facing product capability over engineering infrastructure.
- The Constitution is **complete**; it changes only through a numbered ADR.

Recorded also in [I-governance §I.13](../blueprint/I-governance.md).
