# M1.19 — BR-1 Three-Engine Browser Environment

## Executive Summary

The next unresolved certification prerequisite in the frozen dependency order of `docs/m1/M1.16-Fresh-Certification-Execution-Plan.md` is **BR-1 — three-engine browser environment** (Recommended Execution Order, row 2, immediately after the retention + destination decision resolved by M1.17/M1.18).

BR-1 is an **Environment** blocker. It was recorded in M1.16 as "Unknown until verified at execution time". This sprint verified it against the repository and the execution image, and the result is worse than Unknown:

- The project pins `@playwright/test` **1.62.1**, which resolves browser builds `chromium-1234`, `chromium_headless_shell-1234`, `firefox-1538`, `webkit-2336`.
- The execution image contains only `chromium-1194`, `chromium_headless_shell-1194`, `firefox-1495`, `webkit-2215`.
- A direct launch probe of all four launch paths (`chromium` channel, default chromium, firefox, webkit) failed with `Executable doesn't exist`. **Zero engines launch today** without an externally provisioned binary or an explicit `CERT_CHROMIUM_PATH` override.

Provisioning browser binaries is not repository code, and confirming that every engine intended for the seal actually launches is, by the frozen Phase 0 exit condition, an environment fact — not an implementation task. Under this sprint's non-implementable rules ("Missing browser/device environment"), **no implementation was authorized**. No substitute engine, no downgraded requirement, no scope reduction of the seal, and no advance to a later prerequisite.
