# M1.18 DEST-1 Resolution Report

## Executive Summary

DEST-1 was **partially resolved** by M1.17. The retention contract already named
`tests/certification/evidence/<RUN-ID>/` and every writer in the repository already wrote
there, but the destination was not _proven_ as one unique, validated path: the root was
re-declared as a bare string literal in four independent places, no code rejected an
unsafe or traversing RUN-ID before constructing a path, and the runner's generated
workspace beneath the run directory was unclassified.

This sprint made the destination authoritative and testable without changing its value,
its retention semantics, or any product behaviour. One resolver module now owns the root,
sealing fails closed on an unsafe RUN-ID, and eight destination checks (D1–D8) run in the
existing retention self-test and existing CI guard.

Verdict: **Yes — DEST-1 is resolved according to the frozen authorities.**

No certification was executed, no certification evidence was generated, no historical
evidence was recreated, and no certification state or semantics changed.

## Authoritative Destination Contract

Documented in `docs/certification/Evidence-Retention-Contract.md` → "Authoritative
destination (M1.18 — DEST-1)".

| Item                       | Value                                                                                                                                                    |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Authoritative root         | `tests/certification/evidence/`                                                                                                                          |
| Per-run path               | `tests/certification/evidence/<RUN-ID>/`                                                                                                                 |
| RUN-ID path                | the run directory; `<RUN-ID>` must match `^[A-Za-z0-9][A-Za-z0-9._-]{0,127}$`                                                                            |
| Work-package path          | `<run>/manifest.json` → `workPackage` (mirrored in `summary.json`, `completed.json`)                                                                     |
| Certification-row mapping  | `<run>/manifest.json` → `rows[]` → `records/<EVIDENCE-ID>.json`                                                                                          |
| Manifest                   | `<run>/manifest.json`                                                                                                                                    |
| Index                      | `<run>/index.json`                                                                                                                                       |
| Summary                    | `<run>/summary.json`                                                                                                                                     |
| Completion marker          | `<run>/completed.json`                                                                                                                                   |
| Report path                | `<run>/reports/`                                                                                                                                         |
| Raw artifact path          | `<run>/artifacts/`, `<run>/videos/` (ignored, non-authoritative)                                                                                         |
| Temporary workspace        | `<run>/artifacts/`, `<run>/videos/`, `<run>/html/`, `<run>/report.json`, `RUN-*SELFTEST*` fixtures                                                       |
| Legacy path handling       | `RUN-M0R-001` remains at the same root, unmodified, without a manifest                                                                                   |
| CI/repository relationship | CI writes to the same root; the uploaded artifact is a derived 90-day copy, never the source of truth                                                    |
| Release-review lookup      | see below                                                                                                                                                |
| External/immutable store   | Not defined by frozen authorities.                                                                                                                       |
| Cross-run master index     | Not defined by frozen authorities. Row/work-package/revision lookup is a scan of `evidence/*/manifest.json`, deterministic because only one root exists. |

Release-review lookup procedure:

1. **From a RUN-ID** — open `tests/certification/evidence/<RUN-ID>/manifest.json`
   (revision, work package, engines, rows, artifact digests), then `summary.json` and
   `completed.json` to confirm the run sealed.
2. **From a certification row** — scan `tests/certification/evidence/*/manifest.json` for
   `rows[].evidenceId`; the containing directory is the run; the record is at
   `records/<EVIDENCE-ID>.json`.
3. **From a work package** — scan the same manifests for `workPackage`.
4. **From a source revision** — scan the same manifests for `sourceRevision.sha`.

There is exactly one root to scan, so each lookup is deterministic and requires no guess
between paths.
