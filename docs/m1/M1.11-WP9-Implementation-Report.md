## 2. Integration review — blocking finding

### Finding WP9-F1 — the selection surface can announce control that is not certified

WP7 made the **launch** surface honest: a catalog row claiming
`play_pause: supported` is downgraded to `manual_sync` unless the capability
certification registry proves Tier A for the tuple
(`src/domain/providers/provider-launch-coordinator.ts`, lines 96–102).

The **pre-commit selection** surface — the surface `CERT-PROV-01` measures —
was not brought under that rule:

- `src/domain/providers/provider-catalog-service.ts`, `deriveSelectionClass`,
  line 120: `if (status === "available" && complianceAction === "allow") return "supported";`
  The class is derived from catalog status and compliance action alone. No
  capability certification is consulted.
- `src/features/providers/components/provider-card.tsx`, lines 71–82, renders
  that class as the badge and hint a user reads before selecting.
- `src/foundation/localization/bundles/en.ts`, line 282:
  `"provider.hint.supported": "StreamFlow can start and pause this together for everyone."`

Consequence: with zero Tier A and zero Tier B capabilities certified
(`src/domain/providers/capability-certification.ts` registry is empty), an
`available` + `allow` catalog row still presents the user with a **"Supported"**
badge and a sentence promising StreamFlow will start and pause the provider,
and only after commitment does the launch panel correct itself to
`Manual sync`. That is a capability overclaim at the exact moment of
commitment, and it is inconsistent with:

- ADR-014 (no OTT playback control is possible or permitted);
- PROV-A1 (a claim is not evidence; tier comes from the certification registry);
- `docs/m1/M1-Product-Experience-Specification.md` §Principle 1 — "Any surface
  touching a Tier C provider states the tier and its consequence before the
  user commits";
- WP9's own acceptance criterion.

`CERT-PROV-01` therefore cannot pass against the current product, and the
correct action is not to weaken the assertion but to make the disclosure true.
